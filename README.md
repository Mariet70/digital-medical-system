# digital-medical-system
My Internship project
This project is the backend of our Digital Medical System, built using Node.js, Express, and a PostgreSQL database hosted on Supabase. So far, I have set up the backend server, connected it successfully to the database, and created basic API routes to test the connection and handle simple user data. I also configured environment variables using a .env file and made sure sensitive information is not pushed to GitHub by using a .gitignore file. Along the way, I faced several challenges such as Git not being available on my school laptop, working in the wrong directory, environment variables not loading properly, and multiple database connection errors caused by incorrect connection strings, wrong regions, and confusion between direct and pooler connections in Supabase. After debugging step by step, I was able to fix these issues and get a working connection. This progress has now been committed and pushed to GitHub so that my teammates can access and continue working on the project.
